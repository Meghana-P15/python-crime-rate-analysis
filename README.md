<h1>📊 Crime Rate Data Analysis and Visualisation using Python </h1>
<H2>Description</H2>
This project analyses crime rate data using Python and visualises the information using graphs.
The dataset is loaded from a CSV file and processed using the Pandas library. The results are displayed using different graph representations created with Matplotlib.

<h2>Technologies Used</h2>
<dl>
<dt>Python</dt>
  <dd>Pandas</dd>
  <dd>Matplotlib</dd>
</dl>

<h2>Dataset Source</h2>
The dataset used in this project was collected from Wikipedia and organised into a CSV file for analysis

<h2>Features</h2>
-Read crime data from a CSV dataset 
-Analyzes data using Pandas 
-Creates line graphs to observe crime trends
-Creates bar charts to compare crime rates between states

<h2>How to run the program </h2>
1. Install required libraries
pip install pandas matplotlib
2. Run the Python file
python main.py

<h2>Output</h2>
The program generates:
<ul>
  <li>Line graph showing crime trends</li>
  <li>Bar chart comparing crime rates between states</li>
</ul>
